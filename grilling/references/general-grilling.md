# General grilling

Use this mode to clarify an unclear problem and to stress-test a non-binary question, claim, plan, or idea. Clarification and stress-testing are two stages of the same workflow; move between them as the evidence requires.

## Stage 1: Frame the problem

Separate the user's statements into:

- verifiable facts;
- interpretations of those facts;
- value judgments;
- desired outcomes;
- material constraints;
- unverified assumptions.

Check vague keywords, hidden premises, evidence sources, plausible contrary explanations, and what it would mean if the current conclusion were true or false. Ask only questions that can materially change the problem definition or later recommendation.

Ask in rounds of up to the two highest-value independent frontier questions. If only one material question remains, or the second depends on the first answer, ask only the prerequisite question. Do not impose a total question limit.

Before the first round, state the tentative understanding based on the investigation. Before each later round, state in one sentence what the previous answers changed in that understanding.

Do not give advice or recommend an answer while the real problem is still being elicited.

The problem is framed when it can be stated as a concrete question with a clear desired outcome, material constraints, an explicit evidence boundary, and visible assumptions.

If framing materially changes what the user originally appeared to ask, stop and present:

1. the user's original question;
2. the problem they appear to be trying to solve;
3. confirmed facts;
4. assumptions that remain unverified;
5. the variable most likely to change the conclusion;
6. one accurate, concrete, actionable new question.

Ask the user to confirm the new question before giving a judgment. If framing only makes the original question more precise without changing its substance, state the refined question and continue without a mechanical confirmation pause.

## Stage 2: Stress-test the framed problem

Build and prune a design tree around the confirmed or stable question. Ask in rounds of up to two independent frontier questions. A dependent question belongs to a later round.

After each round, update the evidence map and reassess practical 95% confidence. Continue only while another answer could materially change the solution. There is no fixed total question count.

When the threshold is met, provide:

1. the judgment or proposed solution;
2. the reasons and evidence supporting it;
3. the conditions under which it applies;
4. material assumptions or limits;
5. the next concrete action.
