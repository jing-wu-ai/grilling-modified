# Two-sided steelman

Use this mode only for a real decision between exactly two clear, mutually exclusive, realistically available options. Do not force a binary frame merely because the user's wording contains “whether” or “A versus B.”

## Verify the decision frame

Investigate the available context first. Give the strongest provisional restatement of the choice and label any assumptions it depends on. Check whether the options are genuinely available, whether they are mutually exclusive, and whether an omitted third path or sequencing option makes the binary false.

If the frame is premature or false, explain the issue and return to general grilling. Otherwise continue.

## Steelman both options before recommending

For each option, present its strongest case, including:

- strongest reasons in its favor;
- conditions under which it is the better choice;
- largest potential benefit;
- largest material risk;
- hardest objection its supporter must answer.

Then identify:

- the real disagreement between the two cases;
- the variables most likely to change the conclusion;
- material information that is still missing.

Do not create artificial symmetry. If the evidence for one side is weaker, represent it fairly without inflating it. Do not give the final recommendation yet.

## Ask the pivotal question

Ask the single unanswered question most likely to change the conclusion. Briefly explain why it matters, but do not recommend how the user should answer it.

After the user answers, state in one sentence what changed in the working judgment and reassess practical 95% confidence. If confidence remains below the threshold, ask the next single pivotal question. There is no fixed total question count, but ask only one at a time in this mode so each answer can reshape the comparison.

When the threshold is met, provide:

1. a clear recommendation;
2. the reasons and evidence supporting it;
3. the conditions under which the recommendation holds;
4. the facts or changes that would reverse it;
5. the next concrete action.
